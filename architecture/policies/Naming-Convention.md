# Naming Convention

## Purpose

This document defines the naming standards used throughout the Enterprise SOC Lab. Following consistent naming conventions makes administration, automation, troubleshooting, and incident response easier.

---

## Domain

```
soclab.local
```

---

## Domain Controller

```
DC01
```

Future examples:

```
DC02
```

---

## Servers

```
FILE01
WEB01
APP01
DB01
```

---

## Workstations

```
CLIENT01
CLIENT02
CLIENT03
```

---

## Administrative Accounts

```
adm.faraz
adm.itadmin
adm.helpdesk
```

---

## Standard User Accounts

Format:

```
firstname.lastname
```

Examples:

```
john.smith
alice.brown
faraz.shaikh
```

---

## Security Groups

```
GG_IT
GG_HR
GG_FINANCE
GG_SOC
GG_MANAGEMENT
```

---

## Organizational Units (OUs)

```
Servers
Workstations
Users
Groups
IT
HR
Finance
Security
Service Accounts
Administrators
```

---

## Benefits

Using standardized naming conventions improves:

- Asset identification
- User management
- Log analysis
- Detection engineering
- Incident response
- Automation
