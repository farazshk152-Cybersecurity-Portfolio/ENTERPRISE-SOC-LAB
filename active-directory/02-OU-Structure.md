# Organizational Unit Structure

The following Organizational Units (OUs) will be created.

```
soclab.local
│
├── Servers
├── Workstations
├── Users
│     ├── HR
│     ├── Finance
│     ├── IT
│     ├── SOC
│     └── Management
│
├── Groups
├── Service Accounts
├── Administrators
└── Disabled Users
```

## Why use OUs?

Organizational Units make it easier to:

- Apply Group Policies
- Delegate administration
- Organize users
- Organize computers
