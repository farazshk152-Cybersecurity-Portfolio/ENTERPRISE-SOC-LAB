# SOC Overview

## Purpose

This document describes the Security Operations Center (SOC) designed for the Enterprise SOC Lab.

---

## Objectives

The SOC is responsible for:

- Monitoring security events
- Detecting suspicious activity
- Investigating alerts
- Responding to incidents
- Improving security visibility

---

## Team Roles

- SOC Manager
- SOC Analyst L2
- SOC Analyst L1
- Threat Hunter
- Incident Responder
- Windows Administrator

---

## Primary Technologies

- Windows Server
- Active Directory
- Windows 11
- Sysmon
- Wazuh
- Kali Linux
- Sigma Rules
