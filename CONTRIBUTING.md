# Contributing

This repository is primarily maintained as a personal cybersecurity portfolio and learning project.

Contributions that improve documentation, detection logic, security analysis, lab architecture, or technical accuracy are welcome.

## Guidelines

- Keep changes relevant to the Enterprise SOC Lab.
- Do not include real credentials, secrets, private keys, or sensitive data.
- Clearly document configuration changes and testing results.
- Do not claim detections, alerts, or attack results that were not actually verified.
- Preserve the educational and defensive-security purpose of the project.
- Keep screenshots and evidence organized by project phase.
- Use clear commit messages describing the change.

## Security

If you identify a security issue in the repository, avoid publishing sensitive exploit details directly in a public issue.

This project is intended for controlled lab use only.
