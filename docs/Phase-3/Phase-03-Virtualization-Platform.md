# Phase 03 – Virtualization Platform Setup

## Objective

Prepare the virtualization platform that will host the Enterprise SOC Lab.

---

## Why Virtualization?

Virtualization allows multiple isolated operating systems to run on a single physical computer.

In enterprise environments this enables:

- SOC testing
- Malware analysis
- Attack simulations
- Threat hunting
- Infrastructure testing

without affecting the host operating system.

---

## Activities

- Install Oracle VirtualBox
- Install Extension Pack
- Verify hardware virtualization
- Prepare virtual networking
- Prepare installation media

---

## Deliverables

- Extension Pack Installed
- Hardware Virtualization Verified
