# Enterprise SOC Lab Overview

## Project Goal

The purpose of this project is to simulate a real enterprise Security Operations Center (SOC) environment.

Rather than installing a SIEM alone, this lab demonstrates how enterprise infrastructure, security monitoring, threat detection, and incident response work together.

The project is designed to showcase practical cybersecurity skills that are expected from a SOC Analyst.

---

## Objectives

- Build an enterprise Active Directory environment
- Deploy Windows infrastructure
- Configure enterprise networking
- Collect endpoint telemetry
- Detect malicious activity
- Perform threat hunting
- Investigate incidents
- Document investigations
- Map detections to MITRE ATT&CK
- Build reusable detection rules
