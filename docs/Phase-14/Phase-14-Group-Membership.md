# Phase 14 - Active Directory Group Membership



## Objective



Assign users to the appropriate Active Directory security groups and verify group membership for the Enterprise SOC Lab.



Group membership provides role-based access control (RBAC) by allowing permissions and security policies to be associated with groups rather than individual users.



\---



## Group Membership Implementation



The Enterprise SOC Lab uses security groups to organize users according to their departments and security responsibilities.



The implemented membership structure includes:



\- SOC users

\- HR users

\- Finance users

\- Enterprise security groups

\- Faraz Shaikh user membership
