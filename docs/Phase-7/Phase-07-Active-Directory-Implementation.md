# Phase 07 - Active Directory Architecture and Implementation

## Objective

Design and implement the Active Directory structure for the Enterprise SOC Lab.

The Active Directory environment provides centralized identity management, organizational structure, security groups, user accounts, and role-based access control for the enterprise environment.

---

## Environment

| Component | Configuration |
|---|---|
| Domain | enterprise.local |
| Domain Controller | DC01 |
| Domain Controller IP | 192.168.10.10 |
| Directory Services | Active Directory Domain Services |
| DNS | Windows Server DNS |
| Client | WIN11-CLIENT01 |
| Network | Enterprise isolated lab network |

---

## Active Directory Architecture

The Enterprise SOC Lab uses a single Active Directory forest and domain.

The logical structure is:

```text
Forest
|
+-- enterprise.local
    |
    +-- DC01
---

## Organizational Structure

The Active Directory environment uses Organizational Units (OUs) to separate different types of objects.

The implemented OU structure includes:

```text
enterprise.local
|
+-- Enterprise
+-- Admin Accounts
+-- Corporate
+-- Finance
+-- Groups
+-- HR
+-- IT
+-- Quarantine
+-- Sales
+-- Security
+-- Servers
+-- Service Accounts
+-- SOC
+-- Workstations

---

## Department Structure

The enterprise environment contains multiple departments:

- Corporate
- Finance
- HR
- IT
- Sales
- Security
- SOC

Each department can have dedicated users and security groups.

This allows department-specific security controls and access permissions to be applied.

---

## Security Group Strategy

Security groups are used to implement role-based access control.

Department groups include:

- GG_Corporate_Users
- GG_HR_Users
- GG_Finance_Users
- GG_Sales_Users
- GG_IT_Users
- GG_SOC_Users
- GG_Security_Users

Administrative groups include:

- GG_Domain_Admins_Lab
- GG_Server_Admins
- GG_Workstation_Admins
- GG_Helpdesk
- GG_Backup_Operators

SOC-specific groups include:

- GG_SOC_Tier1
- GG_SOC_Tier2
- GG_Threat_Hunters
- GG_Incident_Response

The use of groups allows permissions and security policies to be assigned based on organizational roles.

---

## User Structure

User accounts are organized according to department and security responsibilities.

The lab includes the user:

`Faraz Shaikh`

---

## Group Policy Strategy

Group Policy is used to centrally manage security settings across domain-joined systems.

The Active Directory design supports policies for:

- Password requirements
- Account lockout
- Security auditing
- User authentication
- Computer configuration
- Security restrictions
- Event logging

Group Policy provides centralized configuration instead of manually configuring each Windows endpoint.

---

## DNS Integration

Active Directory relies heavily on DNS for domain operations.

The Domain Controller provides DNS services for:

`enterprise.local`

The Windows 11 client uses DC01 as its DNS server.

This allows the client to locate Active Directory services and Domain Controller resources.

## Active Directory Implementation

The Active Directory environment was implemented on DC01.

The implementation included:

1. Active Directory Domain Services installation
2. Domain Controller promotion
3. DNS configuration
4. Organizational Unit creation
5. Security group creation
6. User account creation
7. Group membership configuration
8. Group Policy configuration
9. Security auditing configuration

The implementation was validated using Active Directory administrative tools and Windows security configuration utilities.

## Security Relevance

Active Directory is a critical component of the Enterprise SOC Lab because it provides centralized identity and authentication infrastructure.

Security events generated by the domain environment can be used for SOC monitoring and detection engineering.

Examples include:

- Successful authentication
- Failed authentication
- Account lockouts
- Privilege escalation
- Group membership changes
- User creation
- User deletion
- Password changes
- Policy changes
- Computer account changes

These events provide realistic security telemetry for the SOC.
